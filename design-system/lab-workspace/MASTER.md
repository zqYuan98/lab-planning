# 部门工作空间设计规范

这是界面的唯一规范。刻度写在 `src/tokens.css`，由 `npm run lint:design` 强制执行；本文说明为什么这样定，以及检查脚本管不到的判断。

2026-11-18 起替代此前的“科技风 / 玻璃质感 / 数字地球”方向。那一版让登录页像宣传页，业务页装饰多于内容，使用者反馈“AI 味重、字段乱、字号多”。

## 原则

1. **页面先给工作，再给解释。** 进入页面第一屏是标题、主要操作和待处理的内容。规则说明、统计口径、流程图解一律放进默认收起的 `<details>`，或放进文档。
2. **只显示使用者要读或要改的信息。** 记录版本号、内部编号、哈希、统计是否去重这类系统内部状态，不出现在列表和卡片上；需要时放在详情页的“历史”里。
3. **同一件事只说一次。** 一个对象在一张卡片上，负责人、状态、截止日期各出现一次。
4. **不做装饰。** 不用渐变、发光、毛玻璃、装饰圆环、背景插画和口号。层级靠字号、字重、留白和一条分隔线。
5. **改界面是替换，不是叠加。** 不新增“覆盖上一版”的样式文件；改哪条规则就改它定义的地方，并删掉被取代的规则。

## 刻度

| 用途 | 变量 | 值 |
| --- | --- | --- |
| 标签、表头、时间戳 | `--font-caption` | 12px |
| 说明、次要信息 | `--font-small` | 13px |
| 正文、表单、按钮 | `--font-body` | 14px |
| 区块标题 | `--font-title-s` | 16px |
| 弹窗标题、页面副标题 | `--font-title-m` | 20px |
| 页面标题 | `--font-title-l` | 24px |
| 指标数字 | `--font-display` | 32px |

字重只有 `--weight-regular` 400、`--weight-medium` 500、`--weight-strong` 600。圆角只有 `--radius-tag` 4、`--radius-control` 8、`--radius-panel` 12、`--radius-pill` 999。间距取 4 的倍数：4 / 8 / 12 / 16 / 24 / 32。

12px 只用于不需要逐字阅读的内容。一段需要读的话用 13px 或 14px。

## 颜色

品牌蓝、导航、页面底和表面使用 `--color-brand`、`--color-nav`、`--color-canvas` 和 `--color-surface`。标题、正文、辅助文字使用 `--color-heading`、`--color-text` 和 `--color-muted`。危险、警告、成功等状态分别配有文字、边框和浅底色，状态同时用文字表达。

业务调色板、标志色和 Arco 组件的主题色均在 `src/tokens.css` 定义。页面引用已有颜色变量。带透明度的阴影与焦点环可以引用同色的 RGB 通道。业务样式中直接写入的色值会计入 `npm run lint:design` 的基线。

## 表单

- 一个表单默认可见的字段不超过 8 个。超出的按用途分组放进收起的 `<details>`，组名说清里面是什么（“交办信息与交付要求”，不是“更多”）。
- 必填字段不放进收起的分组。只在特定状态下需要的字段（如变更原因）在触发条件出现时才显示。
- 新增字段前先回答：谁填、多久填一次、不填会怎样。答不出来的不加。流程见 `.claude/skills/add-field`。

## 列表与卡片

- 一个条目的标签不超过 3 个：状态必显示；优先级只在“高”时显示；类型只在非默认时显示。
- 行内操作不超过 2 个，其余进“更多”菜单。破坏性操作不和常用操作并排。
- 数值全为 0 的列不占表格宽度。

## 文案

写“这是什么、下一步做什么”。不写口号（赋能、聚焦、让……可见），不向使用者解释系统如何统计。按钮用动词开头，同一动作全站同一个词。

## 检查

`npm run lint:design` 会拦住：刻度外的字号、字重、圆角；毛玻璃、文字发光、大字距；口号式用语；以及颜色字面量、阴影、`!important`、内联样式数量的回升。脚本管不到的四条（工作优先、字段数、标签数、同一信息只出现一次）在评审时对照本文检查，步骤见 `.claude/skills/ui-change`。

手机检查宽度 375px，桌面 1440px。主要触控目标不低于 44px。保留焦点轮廓和 reduced-motion 行为。
