# 部门工作空间设计规范

## 方向与依据

保留 Arco Design、实验室品牌与既有业务结构。2026-09-22 根据用户提供的部门概览与工作清单参考图，工作区统一采用深海军蓝导航、浅蓝灰画布、白色内容面板和品牌蓝主操作。业务页通过清晰的中文字号、深海军蓝文字、字重、对齐和留白建立层级，保持长时间阅读与表格操作的清晰度。登录入口继续沿用深海军蓝背景、数字地球、蓝青色边缘光和玻璃质感表单。

本次 ui-ux-pro-max 查询以 SaaS 工作空间为边界，采用匹配到的 Glassmorphism 表面层次与表单可访问性建议；配色及布局以用户参考图为准，不采用推荐中的橙色强调或营销页面结构。保留中文系统字体，不引入远程字体、动画库或 WebGL 依赖。数字地球使用本地静态 SVG。

## 视觉约定

- 工作区品牌蓝：#1769ee；导航：#071d3a；导航强调：#75dcff；页面：#f3f7fc。标题：#0d2342，正文：#2b4565，辅助文字：#5b6f88；占位与禁用文字使用 #7a8ca2。危险、警告、成功保留原语义色。
- 登录页默认深色，提供独立的浅色切换并在本机保存偏好；内部页面保持适合日常阅读的浅色内容区。登录样式隔离在 auth-tech.css，业务主题覆盖集中在 workspace-tech.css。
- 核心页面标题桌面 32px、移动端 26px；区块标题 16px；列表标题 15–16px；说明与元信息 12–14px；表单输入 14–16px。指标数字桌面 40–44px、移动端 31–34px。
- 间距以 8 / 12 / 16 / 20 / 24 / 28 / 32 / 40px 为基础，标题区与主内容相隔 28px。
- 控件圆角 10px，面板 14–18px。表格保留清晰分隔线，背景使用白色与轻微区分的浅蓝灰功能区域底色。
- 日常操作按钮桌面 44–48px，手机主要操作至少 44px；行操作保留足够点击面积与间距。
- 状态同时用文字与颜色表达；状态标签保持完整。保留焦点轮廓与 reduced-motion 行为。

## 页面规则

- 所有业务页面先呈现 h1、说明和主要操作，再呈现工作内容。
- 过滤条件放在统一工具栏中；日期控件不得因 Flex 收缩与搜索框重叠。
- 月度目标与资料导入的静态流程说明使用原生 details / summary，默认收起，可通过键盘访问；上传与审批等实际操作始终可见。
- 概览统计来自真实业务数据；月度目标、周执行、待处理事项和周次索引保持各自职责。
- 部门概览和工作清单在超宽屏使用约 1800px 主内容上限；概览六项指标等宽，工作清单四项指标等宽。指标卡只用低饱和语义色突出图标、边框和状态，数字始终使用主标题色。
- 任务优先级继续由左侧色条、文字和标签共同表达；月度计划与临时任务分别使用蓝色和紫色标签，不能只依赖颜色。
- 手机表格可在自身容器中滚动，页面整体不得横向溢出。主要检查宽度为 320 / 375 / 768 / 1024 / 1440px。

不改动权限、表单字段顺序、审核、提报或报告保存规则。新增页面沿用这份规范。
