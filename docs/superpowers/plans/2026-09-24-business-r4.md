# R4 业务补齐实施计划

> **For agentic workers:** Use superpowers:subagent-driven-development with explicit file ownership and independent review.

**Goal:** 按用户确认口径完成 ER-10–14 的业务能力与本地验收。

**Architecture:** 年月/投入复用领域模型，负责人读取与审核队列使用独立最小权限 DTO，报告代理扩展月周期。保留旧快照、指纹和恢复语义。

**Tech Stack:** TypeScript、React 19、Express、SQLite、Word DOCX、node:test。

设计见 `docs/superpowers/specs/2026-09-24-business-r4-design.md`。基线 `caba8f8`，分支 `codex/business-r4`。用户已授权实施并确认三组业务口径，不重复请求启动许可。
