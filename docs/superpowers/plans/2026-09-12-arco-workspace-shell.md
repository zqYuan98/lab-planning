# Arco 整体框架实施计划

1. 安装并锁定 Arco React，检查 React 19 支持及组件 API；设置中文 ConfigProvider 与所需组件样式。
2. 抽取 WorkspaceShell，实现品牌侧栏、权限菜单、持久折叠、面包屑、主操作、账号菜单和手机 Drawer。
3. 搜索输入接入 Arco Input，保留搜索索引、键盘交互与权限；App 保持数据和导航职责，接入受控报告离开 Modal。
4. 新增限定在外框的响应式样式，保留业务页主题；构建、运行现有回归并修正兼容问题。
5. 在隔离实例中按设计验收管理员、成员、报告导航保护和各尺寸；保存截图与验证记录，交付可预览的本地结果。
