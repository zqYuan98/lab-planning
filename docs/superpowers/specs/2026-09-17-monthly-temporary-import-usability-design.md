# 月度临时目标与导入操作补齐

用户要求月度目标允许新增临时计划，支持文件和图片直接拖入数据导入，并允许删除历史导入。用户已选择跨月管理方式：每月记录阶段目标，未完成时跨月承接。

## 月度临时目标

成员可新增本人负责的临时月度目标，填写当月阶段成果、验收标准、截止日期与临时原因；本人草稿和退回项可修改、提交，管理员审核并发布。普通月度目标继续由管理员建立与维护。已提交项由管理员退回后再修改，成员可查看本人退回原因。

管理员可建立临时目标，并使用既有跨月承接流程延续未完成目标，保留来源、临时标记及原因。月度截止日期仍在所属月份内，每周任务按既有规则关联已发布目标。

新增字段采用可选值兼容旧数据；业务 JSON 导出、恢复保留临时信息。权限校验覆盖新建、修改、提交、审核与发布，不能通过临时入口更改他人目标。

## 文件与图片输入

文件选择、拖入文件以及粘贴截图共用上传入口。支持现有 XLSX、CSV、TSV、TXT、PNG、JPG、WebP，每个文件最多 10 MiB。多个文件逐个处理，每个文件独立保存为批次，反馈成功和失败，不忽略后续文件。文本粘贴保留原行为。

上传区域提供拖入提示、聚焦操作与处理中状态。拖入时阻止浏览器直接打开文件；文件和图片依然先保存，再由用户触发现有识别与校对流程。

## 删除导入历史

提供两个明确操作：删除导入批次、删除单条历史资料。删除前在应用对话框说明对象与影响范围，取消时不做变更。

删除批次移除批次及其归档历史；原文件在无其他批次引用时清理。已生成的月度目标、任务、周记录和已保存报告保留。解析中的批次禁止删除，版本冲突提示刷新重试。

删除单条历史资料保留来源批次和其他行；已提交行的去重信息保留，重复确认不会重新生成被删除的历史资料。删除操作留审计记录，接口按管理员、批次所有者及历史资料归属校验权限。

## 验证

覆盖成员临时目标提报、退回修改、管理员审核发布、跨月承接、旧数据兼容及迁移；覆盖批次与单条历史删除权限、版本冲突、解析并发、共享来源、重复提交与正式数据保留。浏览器使用隔离内存库验证拖入文件和图片、粘贴截图、删除取消/确认及成员入口。运行相关测试、完整测试与生产构建。
