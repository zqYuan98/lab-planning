# 部门概览多维视图

## 问题与选择

现有部门概览截取 4 条月目标和 3 条周记录，缺少全员任务矩阵，无法看清没有安排任务的成员。增加更多统计卡仍不能回答“每个人正在做什么”；完全复制通用表格编辑器会扩大任务范围。本次采用共用任务数据的多视图工作空间。

参考飞书仪表盘的分组、实时联动及明细下钻，以及钉钉 AI 表格的表格、看板、时间视图。只实现当前业务数据支持的维度，不虚构 AI 分析、工时或甘特起止日期。

- 默认全部周期的全员工作表，显示所有在用且已获准的账号，保留有任务的停用及历史成员；零任务人员仍显示。
- 任务明细、状态看板、项目汇总、按截止日期定位的时间排期，共五种视图。看板支持状态、负责人、项目分组。
- 全部、按月、按周选择；统一搜索、负责人、项目、状态、风险筛选，任务数和图表跟随相同数据。
- 人员表支持字段显示与排序；保存命名视图到按当前用户隔离的浏览器存储，不保存业务数据。
- 点击任务或汇总数展开完整明细，可进入对应周记录、月目标和安排周工作。

## 数据口径与边界

以 Bootstrap 中可见任务编号为单位去重，挂接周期内周记录，孤立历史周记录亦保留。成员权限继续仅本人可见；普通成员沿用个人工作台。

任务状态取选期最新周记录。草稿独立分类，未排周表示选期没有记录；周记录纳入统计不代表整份周提报已交，周自报完成不等同月度成果验收。项目及目标取周记录保存的目标链接，避免任务跨月改挂后篡改旧记录归属。月视图同时纳入目标月份、截止日期命中的任务。

逾期按当前任务截止日期与今天比较，历史视图不声称还原历史截止日；时间排期仅显示已知截止日期，未设置日期的任务单独列出。

不增加通用字段编辑器、拖拽修改业务状态、AI 推测统计或跨浏览器视图同步。

## 验证

模型测试覆盖跨周去重、草稿、零任务成员、历史账号、同名成员、月归属、权限及逾期。浏览器使用独立 SQLite 合成数据验证五视图、筛选联动、明细、保存恢复和窄屏滚动；应用构建及现有回归测试继续执行。

## UI 优化（用户确认功能后的修订）

使用用户指定的 `ui-ux-pro-max`。本地检索命中 Data-Dense Dashboard、Table Handling、Color Only，以及 React 的可访问查询和共享状态指引。保持现有蓝色品牌，调整为白色工作面板、柔和分隔、明确文字层级；次要提示折叠，常用视图移入设置，使任务更早出现在首屏。

- 人员表突出姓名与任务，弱化竖向网格；每项任务显示状态文字，逾期另外标注。
- 支持舒适、紧凑密度，保存视图包含密度配置；旧视图无密度字段时按舒适显示。
- 手机使用人员卡片，保留全量任务、零任务成员与统计；筛选默认折叠，当前条件显示为可移除标签。表格字段配置仅在桌面表格提供，避免手机出现无效设置。
- 看板任务卡突出标题、项目、负责人及截止日期，状态分组和项目统计保持原口径。
- 复核 1440px 桌面、375px 手机及中等宽度布局，检查长任务换行、可见状态、键盘操作、筛选恢复和正文对比度。数据与正式服务器保持原状。
