# Arco 工作空间整体框架

用户在整体 UI 优化方案后选择“整体框架”，本轮据此落实侧栏、顶栏、搜索入口和账号菜单。

## 设计

使用 @arco-design/web-react 的 Layout、Menu、Button、Breadcrumb、Avatar、Dropdown、Drawer、Input、Modal。保留天枢实验室 Logo，使用白色侧栏、浅灰工作区和品牌蓝主操作。桌面侧栏宽 232px，折叠后 72px；顶栏高 72px，展示当前位置、搜索、角色相关主操作和真实账号。内容区域随侧栏宽度调整，既有业务页继续使用现有主题。

900px 以下使用抽屉导航，顶栏允许搜索独占一行；手机隐藏账号文字和面包屑分组以控制密度。所有导航项具备文字或可访问名称。菜单支持键盘操作；移动抽屉支持 Escape、遮罩关闭和焦点恢复。搜索保留 / 快捷键、键盘选择、当前可访问数据索引及定位逻辑。

侧栏的展开偏好使用带命名空间的 localStorage 键保存，读取或写入失败时使用内存状态；屏幕变大时关闭移动抽屉。账号菜单显示真实姓名与角色，提供退出登录。所有页面切换、搜索、主操作和退出继续走 App 的权限判断及报告未保存确认。顶部提供跳至主要内容的键盘链接。

## 边界与实现

新增 WorkspaceShell 组件集中处理外框，将 App 中的品牌、菜单及布局抽离，App 保持现有数据请求、路由意图、权限和退出逻辑。全局 ConfigProvider 配置中文；Arco 样式采用组件样式导入，避免引入不使用的业务控件样式。外框使用独立类名，避免覆盖原业务页面、原生表单与原有弹窗。登录页面保留既有品牌布局。报告离开确认使用受控 Arco Modal，保留继续编辑和放弃编辑两个动作。

不改动服务端、数据库、审批规则、周提报时限、报告快照、业务页表单字段和搜索结果的数据权限。本轮仅本地实现与验证，不部署正式服务器。

## 验收

- TypeScript 与生产构建通过，运行现有回归测试。
- 独立数据库和合成账号浏览器检查管理员/成员侧栏、主操作、折叠与刷新偏好、搜索跳转和账号退出。
- 验证报告未保存时通过侧栏、搜索及退出触发确认，取消后仍留在报告编辑页。
- 检查 1440px、1024px、390px、320px 及低高度窗口，导航可滚动，抽屉不会使底层页面可交互，顶栏无横向溢出。
- 记录浏览器错误并截图检查实际显示。Arco React 19 兼容性以实际构建和浏览器交互结果为准。
