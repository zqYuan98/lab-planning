# 浅色工作空间界面设计

用户已提供明确的参考图、七项修改要求、颜色 token 和正式 Logo，并要求直接调整整体风格。本轮沿用已批准的业务模型，实施该指定视觉方案。

- 背景 #F7F8FB、卡片白色、描边 #E8ECF3、主色 #3B5BFF。侧栏约220px，内容最大1180px，圆角12–16px，轻阴影。
- 侧栏按规划/资产/团队组织，当前账号名读取实际账号；首位管理员姓名默认袁中群。使用用户原始Logo图，无替换品牌或模拟头像。
- 顶栏真实搜索可访问的计划、任务、项目、成员，结果跳转并定位；管理员固定审核月度计划按钮，成员为安排本周工作。保留报告离开保护。
- 概览包含紧凑周期状态、四项不同形态指标、月计划到周执行主工作区、本月真实周节奏、协作待办、快捷入口。
- 指标来自bootstrap可见数据。无历史数据不虚构上升趋势，零分母显示无待办或暂无记录。周节奏按真实日历显示4–6周，过去日期不等于工作完成，跨月周正确截取。
- 快捷建项目直接打开新建表单；写周报进入当周草稿或生成入口；审核、阻塞、搜索目标分别带入真实筛选或详情。协作提醒是查看待办，不发送消息。
- 全部业务页与登录、模态框、报告中心统一浅色字体和控件；不改变后端业务权限、统计与报告快照。

验证包括生产构建、现有回归测试、日历与统计关键边界、桌面/手机、空数据/有数据、搜索/快捷入口/未保存报告导航保护。使用隔离验证数据库，不改用户业务数据。
