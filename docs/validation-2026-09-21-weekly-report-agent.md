# Word 周报模块实施与验收

日期：2026-09-21。范围：已批准设计的阶段 A/B，先实现周报，复用底层为后续月报做准备。本次为本地实现与验收，没有发布生产版本、修改生产数据库或开启用户的自动任务。

## 使用路径

1. 管理者在「报告中心 → 周报模板与生成 → 模板与范例」上传 DOCX 模板，可同时选取历史成品范例。每份最大 12 MiB，最多选择 10 份学习范例。模板与事实导入用途分开：范例不会写入月目标或周工作成果。
2. 查看原文，确认每段、每张表或每格的处理方式。支持保留固定标题、清空旧示例、元信息、成果/风险/下周安排重复表格以及人工补充。默认建议仍须人工核对。
3. 配置 AI 后可学习范例写法；学习只形成候选规则，由管理者逐条采纳、保存并确认。未配置 AI 时提供通用规则建议，并明确说明来源。
4. 生成试填 Word，下载并在实际 Word 客户端检查字体、表格、页眉页脚和分页，填写核对说明后启用。发布后的模板不可原地修改；公司换模板时建立新版本。
5. 选择周次和有效模板，生成待审阅草稿。报告冻结读取时的事实、模板版本和规则；补生成显示实际读取时间，不伪称历史时点快照。月目标验收、周阶段自报完成及任务整体完成分别表达。
6. 逐格审阅来源。公司指标、风险方案 A/B、代价、组合字段和无法推断的日期保持人工补充，填写依据并确认。可以单独改写有事实依据的章节；人工字段不自动改写。
7. 保存后预览 Word，填写定稿说明并确认。定稿保存独立 DOCX 文件与校验和，以后下载相同字节；旧报告导出入口也复用该归档。定稿后如需修改，生成新版本。

网页 Word 预览用于内容与结构核对；字体与自动分页以本机 Word 为准。原报告编辑、规则报告和月报入口继续可用，智能体报告不能通过旧编辑/定稿接口绕过校验。

## 可靠性与安全边界

- 资产和全量报告仅管理者可访问。上传先验证登录和角色，再解析大请求；上传接口限 18 MiB，模板/表格编辑限 4 MiB，其他普通接口仍限 256 KiB。Nginx 示例增加对应窄路由配置，部署时需同步。
- 原 DOCX 保留。填充修改正文 XML，其余受支持部件逐字节保留；复制重复行清理重复标识、替换范围不残留历史数据。
- ZIP 条目数、压缩/解压大小、CRC、目录路径和 XML 大小均有界。拒绝宏、外链、直接 VML 资源、嵌入对象、修订、批注、隐藏内容、非法 XML 字符和携带业务内容的 customXml；空书目元数据按明确结构兼容。复杂不支持区域给出原因，要求清理副本后重传。
- 模型只能提交带冻结事实 ID 的候选。验证对象、源记录、版本、周期、数量单位及完成/验收状态；失败仅重试一次，随后保留原文并提示。该规则校验不是通用语义证明，仍保留管理者内容审阅。
- 后台作业持久化进度、租约及请求编号，支持取消、失败重试和失效租约接管。人工保存让旧任务失去提交资格，重试跳过人工改过的区域；模型回退的区域可显式重试。停用账号不能继续提交模型结果。
- 逐格编辑保留本标签页草稿，版本冲突不覆盖输入；本地存储超限/失败时明确提示没有备份，不声称可恢复。服务端报告正文最多 120000 字。
- 调度使用 Asia/Shanghai，默认关闭。启用后只接管旧周报调度；停机只补最新一期，历史遗漏保留可见，修改调度不会静默抹掉遗漏。
- SQLite 完整备份保留全部数据。业务 JSON v4 包含模板/范例/试填/定稿原件及报告冻结内容；账号映射后重新计算快照哈希并保留迁移前哈希，定稿字节不变。恢复核对 DOCX 实际结构、模板完整映射与试填指纹。业务包不包含运行租约、自动作业或调度，避免恢复后重放。JSON 包上限 32 MiB；较大数据使用完整数据库备份。CSV/Excel 只含 Word 文件元信息。

## 验收证据

最终检查：`npm test` **654/654 通过**；`npm run build` 通过（包含全量 TypeScript 检查）。新增 Word 预览按需加载；构建仍有现有主包超过 500 kB 的提示，不影响构建结果。

- 读取用户提供的两份真实 Word 周报，均含六张表；原文件 SHA-256 在操作前后保持一致。真实业务内容未加入 Git，也未发送到外部模型。
- 使用真实模板与合成任务/成果生成 Word。本机 Microsoft Word 16.0 正常打开、重分页并导出 3 页 PDF；逐页检查了固定标题、长内容表格、重复表头、下周安排、异常事项和页码。修正了「汇报日期」固定标签的识别和「当前措施 / 责任人」组合列的人工补充方式。
- 浏览器完成登录、上传真实模板、选择范例、获取规则候选、采纳保存、生成试填、启用模板及归档预览；手机 390 px 视口无页面横向溢出，表格和 Word 预览在局部容器滚动。
- 对本地测试库执行实际在线 SQLite 备份，再独立打开备份库；模板记录和定稿 Word 字节、SHA-256 与源库一致。
- 单元/集成回归覆盖 ZIP/XML 边界、原件保留、模型数量/单位/对象串用、伪造占位前缀、人工编辑竞争、取消/重试/权限变更、定时补跑、HTTP 上传权限与请求限制、业务迁移及定稿字节一致、草稿恢复和确认表单。
- AI 流程通过模型 stub 验证，未连接生产模型做业务生成。Linux 容器与公网验证应在正式发布时按现有部署流程执行。

本地验收产物放在 Git 忽略的 `output/weekly-report-agent/` 与 `output/playwright/`。合成生成文件不是可直接对外提交的正式周报。月报模板迁移、月报自动生成、独立周/月分析报告及反馈学习属于后续阶段，本次不标为已完成。
