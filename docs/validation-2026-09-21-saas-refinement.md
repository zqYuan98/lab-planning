# SaaS 界面与任务辨识优化

2026-09-21，本地实现与验收完成，尚未发布至正式服务器。

## 实现范围

参考 [Linear 优先级](https://linear.app/docs/priority)、[Linear 标签](https://linear.app/docs/labels)及 [Asana 自定义字段](https://asana.com/features/project-management/custom-fields)中分别表达优先级、类型、状态的方式，统一部门概览、个人工作台、月度目标、周计划、进展与催办及我的工作清单。

- 高／中／低优先级采用红／琥珀／灰蓝色；未设置保持独立中性标签。卡片色条、信号图标、中文标签共同表达，不依赖颜色单独辨识。
- 月度计划用蓝色，临时任务／临时目标用紫色，日常任务用中性蓝灰色。逾期、阻塞、审核与整体完成状态独立呈现。
- 个人任务显式优先级优先，其次继承关联目标；历史周记录引用原周记录对应目标。临时任务纳入月度目标时，保留的临时原因继续用于识别来源，不改写存储状态。
- 工作清单新增优先级与工作类型组合筛选。汇报预览和导出与当前列表子集、排序、优先级和范围说明一致。
- 成员摘要最多展示三项，优先展示未完成风险和高优先级任务；“查看全部”保留全量入口，统计数量不变。
- 来源、交付说明和统计口径可按需展开；关键风险、审批要求和受阻原因仍直接展示。指标卡、任务卡和字号层级同步优化并适配手机。

## 动效与可访问性

按后续反馈，文字改为中性墨色层级：标题 `#18181b`、正文 `#27272a`、说明 `#414147`；编号、页脚采用 `#5e5e67`。任务进展正文提高至 13px，字段标题和日期采用 12px，字段标题适当加粗；概览表头、催办正文和独立汇报预览同步调整。保留任务优先级、类型、警告与选中状态的强调色；修正月度表格元信息规则覆盖类型标签文字颜色的问题。后续样式调整已单独通过生产构建及桌面、390px、320px 浏览器检查。

遵循用户指定的 animate 技能：仅针对操作反馈与状态说明添加按钮按压 160ms、说明展开透明度 200ms，以及图标轻量反馈。使用 CSS transition 和 `cubic-bezier(0.23, 1, 0.32, 1)`，没有引入动画依赖。

悬停位移限精细指针设备；键盘操作立即响应；减少动态效果时移除位置和缩放变化，保留温和颜色／透明度反馈。弹窗焦点圈定包含可见 summary，支持 Tab/Enter 展开说明和焦点循环。

## 验证结果

- 当前完整项目 TypeScript 检查与生产构建通过。
- 完整 Node 测试 **660 / 660 通过**，包括新增的优先级继承、临时来源、历史关联和摘要排序回归。
- 管理员桌面实测：部门表格、状态看板、时间排期、工作清单、月度目标及周计划。
- 成员实测：高／中优先级、组合筛选、清除筛选、空结果、单项与空汇报，以及打开编辑后字段保留。
- 390px、320px 的工作清单／周计划／月度目标均无页面横向溢出。
- 月度临时目标详情说明可通过 Tab 聚焦、Enter 开闭；键盘模式禁用过渡；减少动态效果时按压无缩放、说明箭头无运动过渡。
