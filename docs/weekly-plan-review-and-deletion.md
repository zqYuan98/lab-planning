# 周计划审核与留痕删除

成员提交整份下周计划，管理者审核指定提交版本。管理员也可删除录错的单条周安排，保留原任务与历史资料。已于 2026-09-21 上线：管理员删除立即可用；审核从 2026-09-28 提报周期开始，覆盖 2026-10-05 起的下周计划，历史计划不补审。详见[上线记录](deployment-aliyun-weekly-review-2026-09-21.md)。

## 提交、审核和时效

这三项记录分别回答不同问题：

| 记录 | 含义 |
| --- | --- |
| 单条周记录正式保存（`submitted`） | 该条不再是草稿；仍须核对整份周提报，适用审批的条目须通过后才纳入正式统计。 |
| 整份提交回执 | 保存本次实际提交时间、条目快照与保留草稿清单；用于计算按时、迟交和截止缺交。 |
| 计划审核结果 | 管理者对一份确定版本的下周计划作出通过或退回结论；不改变原提交时间。 |

成员先填写下周承诺，在周提报区核对整份内容，选择将草稿纳入提交或继续保留，然后提交。没有下周安排时填写说明。管理者打开“审核计划”，核对提交时的承诺、任务与月目标上下文，选择通过或退回；退回必须写明修改意见。

退回后，成员修改相应条目并重新整份提交。旧提交与审核意见保留，新版本重新等待审核。审核时若条目已增加、删除或承诺已改动，系统要求刷新并重新提交，避免批准旧页面上的内容。

已批准的承诺变更后，变更条目暂不计入正式周计划；未变更条目继续使用原批准。补充实际成果、证据、阻塞说明、下一步或执行状态，可以正常保存，不撤销计划批准。本周执行情况发生变化时，仍按实际汇报需要重新提交本周完成情况。

管理员正式下发的安排属于已确认来源，整份提报中仍展示。管理员代录、下发草稿，以及成员修改下发安排的计划内容，仍须按适用周期审核。周计划通过不代替月度目标发布或月度成果验收；目标参与人员、所属周与月份相交、临时工作原因等校验继续生效。

## 删除和重新安排

仅管理员可以使用“删除周安排”。确认窗口展示成员、所属周和承诺，删除原因必填。删除后该条退出当前列表和新统计，原行作为删除记录保留，不能继续编辑或承接。

删除不会删除任务、改变任务完成状态，也不会删除月目标、其他周安排、历史进展、整份提交回执或报告快照。该条关联的待处理催办、阻塞支持和待确认通知失效，历史回应保留；任务的其他催办不受影响。删除也不会清除原迟交或缺交事实。

若要纠正早期未关联月度目标的安排：

1. 管理员填写原因删除旧周安排。
2. 点击删除结果中的“调整原任务月度关联”，补充或调整月度目标。目标须已发布，原任务负责人须参与该目标；保存后保留重建入口。
3. 使用删除结果中的“沿用原任务重新安排该周”，为同一任务建立新周安排。所属周须与目标月份相交。
4. 核对并重新提交整份计划；新安排按其来源和生效规则审核。未来周的“返回核对”会进入前一提报周期的下周计划。

任务已经关联正确目标时，可直接重建。同一任务同一周只允许一条未删除安排；删除记录不占用这一位置。当前不提供删除恢复入口。原提交若包含被删除条目，需要重新核对和提交；历史页面继续展示原版本。

## 生效、暂停和恢复

系统首次启用计划审核时，将下一个完整提报周期保存为生效周，审核内容是该周期的下周计划。例如生效提报周为 9 月 21 日，则覆盖 9 月 28 日当周计划。具体日期以界面显示为准；服务重启不会顺延日期，原有历史不会补造批准或要求补审。

“周提报规则”的暂停与恢复均从下一个完整周期生效。暂停周期不产生应交项和缺交，也不要求计划审核；该周期正式保存的周安排按免审口径生效。系统保留原审批依据及暂停标记。恢复后，新开放周期的成员计划重新按规则审核，恢复生效前的暂停周期继续免审，原提交、审核与报告历史不变。

## 导出和迁移

管理员业务 JSON 包保留删除记录、同任务同周的新安排、审批依据、审核集合以及冻结的任务和月目标上下文。账号映射同时映射删除人、审核人、责任人和历史审批指纹中的账号，恢复只对未删除行检查同任务同周唯一性。

旧包仍可恢复。如果旧包缺少审批元数据，恢复预览会把适用当前审批周期的成员自报、代录和下发草稿列为待审核；已正式下发安排、历史周和已有冻结快照保持原语义。旧包规则缺少审批生效周时，继承目标服务已保存的边界，预览会说明这一处理。恢复不会据此补造审核通过记录。

当前有效批准不能引用已作废的提交；历史报告和审计可以保留作废前的批准事实。暂停标记须与当前规则窗口一致，不能用来跳过开放周期的审核。成员导出仅包含本人的业务事实，不包含部门规则、完整名单及部门报告；完整迁移使用管理员导出包。

恢复先预览再确认，写入失败整体回滚，不产生站内新通知或外发投递。详细接口见[API 契约](api-contract.md)，迁移操作见[智能导入与数据迁移](intelligent-import.md)。
