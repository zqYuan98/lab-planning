# 月度重复目标删除验证

## 验收范围

依据 [删除方案](monthly-goal-deletion.md)，补齐未发布目标删除、成员自提来源权限、保留历史与来源去重，以及所有当前读取和写入口。实现包含发送前重新核验原生待办状态，避免异步查询期间删除后仍按旧状态创建外部审核待办。

## 自动化验证

- 删除权限：管理员四类未发布状态；成员本人临时草稿/退回与有创建审计的历史普通自提；无关成员、观察员、停用账号、管理员分配/导入目标均受限制。
- 事务：版本过期、缺少原因、已发布/合并、发布历史、有效任务/周安排、曾提交或有成果的历史、承接关系拒绝；失败无部分写入。
- 已删除目标的编辑、提交、审核、发布、合并、成果、承接、任务及周安排关联均拒绝；旧链接保留只读历史。
- 统一读取：当前月度列表及计数、发布/关联候选、工作清单、个人/部门概览、待办、年度目标、报告新快照排除删除记录。已删除视图、完整业务导出、审计及既有报告保留。
- 钉钉和普通导入保留来源账本，删除后重新读取不重复新增，旧批次不能复用或激活目标；失败整批回滚。
- 迁移验证删除人映射、状态/时间、有效任务引用；历史参与者导出保留合法脱敏说明，历史投影仍不允许恢复成当前目标。
- 原生待办以 mock 验证：既有审核/验收 todo 和 card 关闭；未发创建取消；身份/绑定失效仍停止外发；不确定请求先对账、不重发。
- 路由矩阵只增加删除预览 GET 和删除 DELETE；匿名401、观察员403，业务权限由域事务继续校验。

## 浏览器与合成数据库证据

独立本地验收服务 `127.0.0.1:4318` 使用新建 SQLite、合成账号；清空外部集成配置，所有服务端 fetch 拒绝外网，不启用调度器。

1. 管理员从「审核月度提报」点击「删除重复目标」，空原因不能确认。填写原因后，当前目标从12减至11，待审核从1减至0，已删除增至1；两条待发布目标不受影响。
2. 已删除详情显示删除人、时间和原因，只能查看历史。
3. 有关联个人任务的目标显示具体处理要求，不出现确认删除按钮。
4. 成员无法删除缺乏本人创建证据的普通目标；可删除本人历史自提退回目标和临时退回目标。
5. 确认卡显示创建方式、创建时间、预期成果，帮助区分同名重复项。
6. 390×844移动端检查确认/取消按钮为44px、无横向页面溢出；关闭按钮也补齐44px触控区域。控制台未发现错误。

只读核验合成数据库确认恰好3条目标软删除、3条审计，关联阻止目标和其他目标均未变化。证据位于 `output/monthly-delete/browser-evidence.json`，测试、构建日志保存在同目录。真实目标没有代删。

## 上线约束

发布采用固定源码和成功CI的本地制品，生产只复制、核验和克隆演练；不在生产构建或执行写测试。删除语义不改数据库结构，但旧版本无法识别标记。维护切换恢复公网前记录不可回退边界；存在月度删除标记时禁止切回旧代码。代码回退校验全程只读，不能用旧备份覆盖生产写入。最终源码、CI、上线与只读验收结果另记部署文档。
