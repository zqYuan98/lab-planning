# 按需查询与性能说明

本文记录公开的查询设计和验收方法。机器规格、原始计时、内存样本、日志路径及内部运行数据不提交到公开仓库。

## 设计

- `/workspace` 只返回安全身份、能力、范围版本、操作环境和配置标志。
- 任务、周记录、月目标、历史、进展、报告和候选人使用独立分页接口。
- 列表和总数在同一读取事务内复用筛选条件。
- 游标绑定筛选、分页大小、身份、权限版本、操作环境和数据版本。
- 权限、身份、恢复或进程代际变化后拒绝旧游标并要求刷新。
- 报告目录与正文分开读取，预览和导出按需加载完整快照。
- 工作清单导出遍历同一筛选范围的全部页面，不把当前页当作全量。
- 历史任务回补只使用当前账号可核验的审计快照。

## 存储与索引

存储升级新增面向活跃任务、有效周记录、审计事件、进展和报告目录的派生索引。迁移在事务中执行，失败时回滚；程序拒绝高于自身支持版本的数据库。

查询使用参数化 SQL 和固定字段投影。进展查询只向应用返回当前展示所需的有限事实，同时在数据库内完成完整性判断。旧页面保留明确的兼容读取路径，未宣称所有历史查询均已迁移。

## 验证方法

使用隔离的合成数据库比较不同历史规模下的响应大小、查询次数、解析行数、延迟和内存变化。验收关注轻量初始化的返回规模与查询次数是否保持稳定，以及分页、权限撤销、游标失效、报告正文隔离和迁移回滚是否正确。

针对性测试、完整自动化测试、类型检查和生产构建均通过。测量结果用于发现回归，不构成生产网络、设备或服务等级承诺。
