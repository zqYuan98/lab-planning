# 浅色工作空间与字体验收（2026-09-08）

## 实现范围

- 220px 浅色分组侧栏、用户上传的天枢实验室 Logo、真实登录账号名称。
- 紧凑月度状态条、四项指标、月计划→周执行工作区、真实月份节奏、协作提醒、快捷入口。
- 使用可访问的真实计划、任务、项目和成员构建全局搜索；结果包含正确的月份、周次和详情定位。
- 审核、发布、项目创建和周报草稿入口保留原有业务权限。协作成员可以阅读被授权的任务，不能更新别人的记录。
- 内置图像生成工具生成两张透明空态插图，详见 `src/assets/README.md`。品牌图原样保留。
- 月计划、周任务、项目、成员、年度目标、报告及登录页面共用浅色主题。

## 字体规范

- 中文优先使用微软雅黑、苹方及系统无衬线字体。
- 输入框、下拉框、文本域：16px；正文、按钮、表单标签：14px；辅助说明：最低12px。
- 正文 `#1D2939`，标签 `#344054`，辅助文字 `#667085`。
- 小屏保留字号，通过卡片两列、流程纵排、时间轴纵排和弹窗滚动适配。
