# R3 页面按需读取与旧路径退役

本阶段对应 ER-06–09。App 的 `/api/workspace` 只携带当前身份、权限范围、操作环境及配置摘要。页面自行读取列表、完整聚合、当前引用和详情，不再从 App 获取所有业务集合。

## 网页读取契约

下表路径均相对 `/api`，使用现有网页登录会话认证。列表默认每页 50 项，最大 100 项；个别页面主动采用更小页长。`total` 和汇总来自完整授权范围，不用当前页条数代替。

| 路径 | 数据边界 |
| --- | --- |
| `GET /workspace/overview/personal` | 当前周期统计、最多 3 项重点条目、4 期趋势，不返回完整任务历史正文。 |
| `GET /workspace/overview/department` | 管理者专用；周期、负责人、项目、状态、搜索及风险筛选；分页任务摘要、完整成员/状态/项目汇总。任务正文另从详情读取。 |
| `GET /workspace/weekly` | 所选周列表及必要引用；周统计独立于文本和状态筛选。 |
| `GET /workspace/monthly` | 所选月列表及完整状态计数、可发布数量；定位对象可在首屏之外。 |
| `GET /workspace/weekly/records/:id`、`/workspace/monthly/plans/:id` | 按当前权限读取完整对象，编辑不会用列表的缩略正文覆盖原文。 |
| `GET /workspace/monthly/publications`、`/workspace/monthly/publications/:id` | 版本目录与原件分开读取，原件保留完整快照。 |
| `GET /workspace/weekly/candidates`、`/workspace/monthly/candidates` | 根据用途和负责人筛选后分页；完整发布/合并确认在用户打开操作时收集全部页。 |
| `GET /workspace/weekly/submission-references` | 提报所需本周、下周引用，独立于周列表当前页。 |
| `GET /workspace/team`、`/workspace/registration-requests` | 管理者目录及审批分页；启停、最后管理者和待审批数量独立计算。 |
| `GET /workspace/projects`、`/workspace/annual-goals` | 项目目录、年度目标分页；年度进展仍由负责人确认。 |
| `GET /workspace/directory/accounts` | 按用途、角色、搜索和选中 ID 读取人员候选；跨页已选项单独保留。 |
| `GET /collaboration` | 分页工作事项、完整状态/风险计数、页内人员与目标引用、最近摘要目录。 |
| `GET /workspace/import-candidates` | 人员、项目、目标、任务候选按条件分页。 |
| `POST /workspace/import-references` | 只读；按当前批次或表单 ID 解析引用，每类每请求最多 100 个，客户端分批读取而非截断。 |

消息、反馈、工作清单、报告、授权工作和历史复盘继续使用各自的专门接口。任务详情只读取该任务的周记录、支持、催办和进展，不扫描其他任务正文。

## 一致性与权限

游标绑定当前账号、角色、权限范围、operation epoch、数据修订及查询参数。数据或权限变化后旧游标返回 `409 WORKSPACE_CURSOR_STALE`，页面提供从首屏重新读取的入口。权限失效、账号切换和操作环境变化会清除旧结果；较晚到达的旧请求不能覆盖当前查询。

成功写入只使相关查询失效。保存回执、草稿恢复和版本冲突保护保留；保存已成功但后续读取失败时，界面提供只重试读取的入口。只读预览不触发业务列表刷新；报告模板“试填”会保存新文件与版本，仍按真实写入处理。

历史成员关系只授予当时可见的计划快照，不能借引用读取当前私有内容。停用成员名称和已选历史引用保留；观察者仍只能读取明确授权的专门入口。

## 导入、导出与兼容

网页导入候选已迁移到上述分页接口。集成 `/api/v1/context` 保留原有完整候选协议，内部改为独立的账号/项目目录、计划和任务读取，不再顺带读取报告、进展或全部工作空间。导入名称匹配只读所需目录。

业务导出独立读取完整授权集合及依赖关系，包括尾页、删除标记、历史引用和发布原件。导出不复用页面分页响应，不受 50/100 项页面限制。

`GET /api/bootstrap` 已退役并返回 404，生产 `Domain.bootstrap` 已删除。旧业务测试使用 `tests/fixtures/legacy-domain.ts` 中的退休快照；独立冻结的 `65317c6` 基线继续用于比较。测试夹具不是可部署的兼容接口。

## 发布与验证

前后端应作为同一版本整体发布；先完成目标环境备份、登录/分页/保存/导出和恢复验收。已有旧页面应通过正常刷新加载新构建，未保存草稿遵循现有离开保护。若回退，应回退整套上一版本，不能仅恢复一个旧接口。

`npm test` 覆盖权限、聚合、历史、尾页、深链和读写恢复；`npm run build` 检查类型和生产构建；`npm run perf` 对 12/36 个月合成数据记录实际页面服务的 SQL、解析量、响应体及耗时。旧 bootstrap 的热点比较明确标记为退休测试夹具。耗时为本机参考，结构指标是 CI 门禁。

部门“全部周期”汇总仍需读取全范围的精简统计字段；完整集成上下文、整月发布确认及导出本来就需要完整授权范围。这些路径不等同于普通列表请求，后续存储重构另按 R6 实施。
