# 功能状态

本文记录公开代码库中的功能范围。部署地址、运行开关、账号数量、通知回执、业务统计、备份位置及内部证据不在公开仓库维护，实际状态以目标环境配置为准。

## 当前版本包含

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 月度目标与跨月承接 | 已实现 | 支持未完成原因、来源继承、幂等承接和发布校验。 |
| 月度目标负责人移交 | 已实现 | 当前参与与历史只读范围分离，页面重读时保留草稿并重新核验身份。 |
| 年月关联与年度进展 | 已实现 | 支持同年度可选关联、承接链去重、自动进展和人工覆盖。 |
| 任务与周执行详情 | 已实现 | 总体任务、每周进展、成果和审计历史分别呈现。 |
| 待我处理与个人清单 | 已实现 | 按当前账号责任和权限汇总，统计覆盖完整筛选范围。 |
| 草稿与冲突恢复 | 已实现 | 支持恢复、三方比较、版本冲突和成功回执保护。 |
| 对象授权 | 已实现 | 管理员可授权观察者，并在撤权后清除旧读取状态。 |
| 目标负责人只读视图 | 已实现 | 当前负责人可读取授权范围内的关联任务和已提交周进展。 |
| 审核委托 | 已实现 | 按提交成员配置，范围不明确或可能自审时由管理者处理。 |
| 数值投入与容量提示 | 已实现 | 区分任务剩余、周预计、周实际以及未填写和零值。 |
| 正式 Word 周报与月报 | 已实现 | 支持独立模板、事实冻结、审阅定稿、下载和调度。 |
| 个人成果与验收 | 已实现 | 保留多版本提交、验收和更正链。 |
| 支持协调与决策责任 | 已实现 | 支持请求、回应、改派、催办和最小权限查看。 |
| 连续跨期流程 | 已实现 | 通过可恢复向导预览并提交目标、任务和周草稿变更。 |
| 历史周期复盘 | 已实现 | 支持期末视角、冻结、定稿、修订和成员隔离。 |
| 假期与调休截止 | 已实现 | 支持固定周五或最后工作日规则，并冻结历史周期事实。 |
| 分页与按需查询 | 已实现 | 各页面独立读取列表、统计与详情，保存后局部刷新。 |
| 缓存、压缩与按需加载 | 已实现 | 提供静态资源缓存、响应压缩和页面级代码拆分。 |
| 最小使用率统计 | 可配置 | 默认关闭，只保存固定枚举和聚合所需的最小数据。 |
| 备份与恢复保护 | 已实现 | 支持在线备份、完整性验证和恢复后的操作环境轮换。 |
| 钉钉协作适配 | 可配置 | 各渠道须在目标环境单独配置并完成企业验收后启用。 |

## 验证范围

当前版本通过针对性测试、完整自动化测试、类型检查、生产构建和性能门禁。浏览器验收使用合成数据，覆盖桌面与移动端关键流程。原始日志、截图、性能样本和部署证据保存在本地忽略目录或受控运维环境，不进入公开仓库。

## 后续范围

更进一步的流程简化、项目里程碑、正式成员评价和跨环境灾难恢复目标需要单独设计与验收。真实使用率与长期运行效果应在明确启用并满足观察周期后评估。
