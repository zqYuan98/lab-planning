# 天枢实验室科技配色改版

根据用户提供的「天枢实验室登录页科技感重设计示意.png」实现本地界面改版。

## 实现范围

- 登录入口：左品牌与月度目标／每周执行／成果汇报介绍，右侧登录表单；本地 SVG 点阵地球、网络网格、蓝青边框，默认深色并支持浅色切换。
- 品牌：按现有六节点网络标识制作矢量组件，适配深蓝导航和登录页。
- 表单：保留真实登录、首次管理员初始化、注册申请及钉钉入口；新增密码显示开关、联系管理员重设密码的提示，不新增找回密码接口。
- 内部：海军蓝侧栏和移动抽屉、蓝青选中指示、浅蓝灰工作区和白色卡片。权限、数据与业务流程不变。
- 响应式：窄屏收起登录流程介绍，优先展示品牌和表单；沿用内部页面的可滚动表格与移动导航。

## 验证

- `npm run build` 通过（TypeScript 与 Vite）。现有大包体积提示仍存在。
- 35 项现有注册、钉钉身份、导航、草稿及反馈客户端测试全部通过，无失败。
- 浏览器使用独立内存数据库 `http://127.0.0.1:4318`，与业务数据库隔离；验证首次创建管理员、密码可见、登录失败保留输入、重新登录、注册申请成功、登录主题切换及持久化、移动导航和月度目标导航。
- 登录错误仅展示错误与定位编号，不展示登录后才可用的草稿恢复和反馈操作；工作区表单沿用原有行为。
- 320 / 375 / 768 / 1024 / 1440px 均未发现页面横向溢出；移动导航文字和按钮对比清晰。主品牌蓝与白字对比约 4.97:1，导航辅助字对比约 7.69:1。
