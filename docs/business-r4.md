# 年度关联、负责人视图、审核委托、投入与月报

本批落实专家审查 ER-10–14。计算与权限口径已由用户确认；本地代码验收与正式环境发布分别记录。

## 年月关联与进展

月目标可以不关联年度目标；关联时必须属于同一年。年度目标保留手填 `progress`，新增 `progressMode`：缺省或 `manual` 使用人工值并显示覆盖标记，`linked` 使用实时计算值。自动值不写回手填字段。

自动进展以本年度关联的承接链为分母，任一未合并节点已验收时该链计为已验收；同链跨月或拆分只计一次，合并来源不另计。没有关联链显示“暂无关联”，不把未知写成 0%。成员页面只汇总其当前有权查看的月目标；管理者看到全部范围。报告冻结生成当时的年度汇总，不随之后修改变化。

同年承接继承关联，跨年承接清空。合并来源关联不一致时必须明确选择或清空。修改年度年份如果会使现有月目标跨年关联则拒绝。

## 目标负责人只读视图

月目标详情提供当前关联任务与已提交周记录。当前目标负责人和管理者可以访问；普通协作成员不会因此获得他人的任务详情。视图只提供任务名称、责任人、状态、截止及周承诺、成果、阻塞和下一步；不返回证据链接、私有任务说明、未提交草稿或以前其他归属的周记录。

这个入口不授予编辑他人任务、普通任务详情或导出权限。任务移出目标、目标换负责人、目标合并或账号失效后，服务端按实时关系拒绝读取；页面根据范围变化、失效响应和重新聚焦清除旧内容。读取日志仅记账号、动作、对象标识、授权目标和结果，不保存正文；日志插入不影响业务分页游标。

## 按提交成员配置审核委托

在周提报的“整份计划审核队列”中，管理者可打开“配置审核委托”。默认全部关闭；按提交成员勾选，不按代提交的管理者配置。只有整份当前计划（包含保留草稿）同属一个有效目标、目标负责人是有效的其他成员、当前任务归属仍匹配时，才委托目标负责人审核。本人任务、多个目标、归属不明或失效均回到管理者，管理者始终可以处理。

每份提交仍只有一个审核结论；队列标识新增、变化、已有批准。审核时重新校验当前账号、配置、任务目标关系、最新提交和完整 manifest，重复请求也重新校验权限。管理者和负责人同时操作时只能有一个成功。沿用原五元计划指纹；执行进展和投入估算变化不会要求重新审核未改动的计划承诺。

委托设置和运行队列不随业务迁移包启用。已作出的委托审核属于业务历史，保留审核者与原结论。

## 投入记录

任务剩余工作量为 `remainingEffortDays`；周预计、实际投入分别为 `plannedEffortDays`、`actualEffortDays`。全部采用非负、有限的数字，以 0.5 人日为步长。未传字段保持旧值，`null` 清空，0 是真实零投入。旧 `estimatedEffort` 文本保留为备注，不推测换算。

周页面与报告按有效周记录汇总，分别列出未填数量；不重复加总任务剩余工作量。周容量超过 5 人日提示复核，不阻止保存。月报按周一所属月份归集人日，跨月周只计一次。后续承接创建的周记录清空预计和实际投入，待重新安排。

导入校对支持年度关联和三项数值字段；导入数字字符串会规范化，普通写接口仍要求数字。JSON、Excel 和 CSV 保留字段；CSV 标识为辅助数据，非正式报告。

## Word 月报

报告模板与生成入口支持周报、月报。月报可选择已上传的 Word 作为来源，创建独立月模板版本，确认区域映射、试填并核对版式后启用。周模板与历史定稿原件保持原状；月模板使用 `monthly-v1`，旧周模板继续使用 `weekly-v1` 及原指纹算法。

月报事实来自当月已发布月目标、月度验收和下月目标，不能把周自报完成当作月验收。生成时冻结事实、年度进展和投入汇总；审阅、人工补充、定稿、下载沿用原模板报告流程。

月报调度独立配置：每月指定日或月末、当月或上月、上海时区。短月份自动取真实月末。错过的历史周期供管理者手动处理，自动调度只处理最近到期周期，同类型同周期避免重复。业务恢复不恢复定时设置或重放任务。

某类型一旦启用过正式模板，旧报告入口中该类型的生成、编辑、改写和定稿均关闭，只保留读取、下载；暂停调度或停用模板不会重开旧入口。尚未配置模板的类型维持原有使用方式。

## 接口与兼容

| 路径 | 合同 |
| --- | --- |
| `GET /api/workspace/annual-goals?year=YYYY` | 分页年度目标与完整授权范围内汇总 |
| `GET /api/workspace/annual-goals/:id` | 年度详情、汇总及分页关联月目标 |
| `GET /api/workspace/goal-owner/plans/:id/tasks` | 当前目标关联任务最小 DTO；支持 q、limit、cursor |
| `GET /api/workspace/goal-owner/plans/:id/tasks/:taskId/weekly` | 已提交进展分页；支持 limit、cursor |
| `GET /api/weekly-review-queue?week=YYYY-MM-DD` | 当前账号可审的整份计划队列，cursor 分页 |
| `GET/PUT /api/weekly-review-delegation` | 管理者配置，写入 version 和 enabledOwnerIds |
| `POST /api/weekly-submissions/review` | 沿用 dutyId、version、submissionId、decision、reason、requestId |
| `POST /api/report-agent/templates` | 新增可选 type，省略仍为 weekly；monthly 周期为 YYYY-MM |
| `GET/PUT /api/report-agent/monthly-schedule` | 独立月调度；0 表示月末，targetMonth 为 current/previous |
| `GET /api/report-agent/policy` | 已由正式模板接管的报告类型 |

数据库迁移 5 只增加关联任务索引，不改写已有实体与冻结报告。含本批字段或月报的迁移包使用格式 8，旧包继续可导入；新包不能降标交给旧程序。恢复前应通过预览校验及账号映射。

正式发布前备份数据库，并成套发布前后端。数据库升级后旧二进制会拒绝直接打开；回退应还原升级前备份并使用对应旧版本，不能让旧程序写入新格式。真实模板的 Word 字体、页眉页脚和分页验收、部署与运行开关启用须在目标环境完成。
