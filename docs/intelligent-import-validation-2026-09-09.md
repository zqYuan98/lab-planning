# 智能导入验收记录

日期：2026-09-09。

用户批准实现图片与表格智能解析、钉钉历史月周计划导入、导出与迁移，并选择在系统内配置兼容 OpenAI 的多模态 API。实现沿用现有月计划提交审核、周记录和账号权限规则。

## 已完成验证

- 自动测试共104项通过：包含已有业务回归，以及表格读取、来源与分块、模型配置、权限范围、后台失败与重启恢复、撤销令牌、重复提交、事务回滚、导出过滤和 JSON 恢复。
- `npm run build` 通过 TypeScript 检查和生产构建。
- `npm audit --omit=dev` 报告0项漏洞。
- 隔离浏览器验收使用内存数据库、合成账号、合成 CSV 和本地模拟模型：上传文件 → 后台解析进度 → 校对修改标题 → 生成月计划草稿 → 月计划页面确认草稿存在。
- 隔离浏览器验收 JSON 恢复：上传合成包 → 预览 → 确认 → 新增项目和对应审计记录。
- 隔离浏览器验收历史纠正：补充成果、填写理由、保存；详情显示新成果，来源原文保持不变。浏览器错误和警告日志为空。
- 用户提供的真实 XLSX 仅在本地只读解析：2个工作表、630个非空源行、33个模型分块，保留合并单元格和周期表头。结构说明见[历史表格结构](historical-workbook-structure.md)。

## 尚需实际服务验证

没有配置用户的真实模型密钥，也没有将真实历史资料发送至模型或写入正式业务记录。连接测试只验证文本 JSON 调用；管理员配置后仍需用实际文本和图片核验服务兼容性与提取质量，再校对确认保存。

当前钉钉资料通过导出 XLSX 导入；在线直连、跨版本 Excel 模糊自动合并和多实例解析调度不在本次实现范围。完整 SQLite 备份包含原始文件及模型配置，业务 JSON 包不包含这些内容。
