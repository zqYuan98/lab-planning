# 图片导入错误修复

2026-09-09，用户上传 PNG 月计划后提示“请选择至少一张工作表”，解析在请求模型前失败。

## 原因和修复

页面对所有文件都提交 `sheets: []`，服务端没有按文件类型区分就进行非空工作表校验。图片和纯文字没有工作表，因此即使配置了模型也无法从页面启动解析。

- 服务端仅对表格执行工作表选择校验；图片和文字忽略工作表参数，兼容尚未刷新的旧页面。
- 页面仅在表格请求中发送工作表选择。
- 无成功分段时明确提示原始资料保留、无需重新上传；上传完成提示不再要求图片选择工作表。
- 原失败批次可直接重试，保留批次编号和原始文件；模型调用成功后清除旧错误。无需修改数据库数据或重新配置模型。

## 验证

- 新增4项真实 HTTP 流程回归：PNG、TXT 携带旧页面 `sheets: []` 成功；表格空选择在调用模型前失败、选中工作表后成功；模拟旧失败 PNG 批次可原地重试。
- PNG 请求断言 `image_url` 中保留完整图片，并选择配置的视觉模型；TXT 使用文本模型。
- 全套108项自动测试通过，TypeScript检查和生产构建通过。
- 隔离浏览器执行 PNG 上传 → 智能解析 → 后台进度 → 待校对1条记录，未显示工作表错误，浏览器错误和警告日志为空。

以上解析验收使用合成图片与本地模拟模型，验证请求和结果流程，不代表对用户真实图片的识别准确率测试。此次没有代用户重新调用正式模型，正式批次仍由用户刷新页面后重试。
