# 成员账号管理

## 停用与日常显示

成员管理默认显示启用成员，可切换停用或全部。停用立即限制登录、接口令牌和新工作分配，保留旧任务及原有责任归属；重新启用后恢复日常显示。

- 部门概览、周计划默认只统计启用成员，勾选“包含停用成员”可查看原历史记录。
- 月度目标默认隐藏仅由停用成员承担的目标；仍有启用协作者的目标继续显示，负责人标注停用。可主动包含停用成员查看其全部目标。
- 新增负责人、协作者、任务归属和导入匹配不提供停用或未审批成员。编辑既有记录时保留原责任人，并显示状态，不能给停用成员新增责任。
- 项目和年度目标属于团队资产，继续保留并标注停用负责人，便于管理员移交。
- 历史报告和冻结提报名单反映当时事实，停用不会删除历史姓名、已交情况或缺交记录；如需变更提报责任，使用原有豁免、更正流程。

## 删除无业务关联账号

在“成员管理”点击“删除账号”。系统先核对关联记录：可以删除时，输入当前姓名确认；存在业务记录时列出阻止删除的类别和数量，可改为停用。

账号承担过的任务、目标、项目、导入资料、业务操作历史、报告快照及冻结提报名单等均保留其责任归属，因此不能物理删除。预览后如新增了业务关联，确认时仍会重新校验并阻止删除。当前登录账号和最后一位有效管理员不能删除。

没有业务关联的账号删除后，其登录资料、会话和接口令牌被清理。账号创建、注册、审批和删除的审计记录仍保留安全身份快照；密码和令牌不会进入审计。原有业务记录和报表不会随账号操作被清理。
