# 变更记录

一次发布一条，最新的在上。只写使用者能感知的变化和需要注意的事项；验证细节留在合并请求里。2026-11-18 之前的发布记录在 `docs/archive/`，不再新增。

## 未发布 —— 界面收敛（分支 `ui/design-consolidation`）

- 全站字号收敛为 7 级、字重 3 级、圆角 4 级；去掉渐变、发光和装饰图形。
- 登录页改为单卡片，去掉背景插画、宣传卡片和口号。
- 部门概览、每周执行的规则说明默认收起；工作事项编辑框默认只显示 8 个字段。
- 新增 `npm run lint:design`，并入 CI。
- 少填原因：发布、发布后调整、跨月承接、合并提报、调整任务关联、核对应交名单、编辑自己的任务不再必须填写原因；退回、删除、作废、豁免、代录以及替他人调整承诺仍然需要。
- 临时目标和临时工作的来源背景、授权说明、指派说明改为选填；跨期向导不再要求先勾选再确认。
- 周记录卡片不再显示内部编号和记录版本，次要操作收进“更多”；任务详情不再显示完整编号。
- 近似色合并（928 → 454 种），视觉无变化。历史发布记录移到 `docs/archive/`。
- 管理者提交月度目标后直接进入待发布，不再经过“待审核”；通过后未发布的目标仍可退回修改。成员提交的临时目标流程不变。
- 发布前需要在本地运行 `npm run build` 和完整的 `npm test`，并在真实浏览器里过一遍登录、概览、月度、周执行、工作清单。
