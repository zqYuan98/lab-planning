### Word 周报模板与生成（2026-09-21 已上线）

已于 18:44 发布至正式站点，管理者可进入「报告中心 → 周报模板与生成」使用；自动周报默认关闭。发布范围、备份及线上验收见[周报发布记录](deployment-aliyun-weekly-agent-2026-09-21.md)。

管理者进入「报告中心 → 周报模板与生成」，上传公司 DOCX 模板和认可的历史成品，逐项确认原文处理方式与写作规则，生成试填文件并在 Word 中核对后启用。生成时冻结当期月目标、周记录和下周安排；报告可逐格编辑、核对来源、单独改写章节、预览并定稿。缺少的公司指标、方案代价和日期要求人工补充来源，定稿文件按原始字节归档。未配置 AI 也可使用规则草稿，配置后才能学习范例写法和辅助改写。

每周自动草稿默认关闭；启用后接管原周报定时生成，旧月报调度继续保留。自动任务只产出待审阅草稿，停机恢复只自动补最近一期，较早遗漏显示供人工处理。业务 JSON 格式 v4 包含模板、范例及定稿 Word；恢复不重放作业或自动启用调度。本期先交付周报闭环，月报模板迁移与独立分析报告仍按后续阶段实施。使用步骤、文件范围及验收见[周报模块实施记录](validation-2026-09-21-weekly-report-agent.md)。
