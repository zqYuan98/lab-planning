# 进展与催办的范围及周完成状态修正

## 根因

管理者的 `/api/collaboration` 返回所有人的全周期 Task，成员仅返回本人 Task；列表包含历史和已完成任务。原列表直接使用 Task.status，周执行表单只更新 WeeklyRecord.status，因此周记录已自报完成时，列表可能仍显示整个任务未开始。原规格已区分两层状态，但周表单缺少明确的“同时完成整个任务”入口。

## 修正

- 列表明确全员/本人、全周期、含已完成的范围，提供整个任务未完成/已自报完成筛选。
- 列表和任务详情并列显示整个任务状态与带周起始日期的周记录状态和成果。优先本周，没有本周则显示最近既往周；未来安排不覆盖当前进展。历史导入完成沿用“原记录标记完成”，不错误归因为成员自报。
- 周摘要仅展示本人草稿或已纳入周统计的记录；读取摘要不更新任务、周记录、进展、通知。
- 周进展表单增加默认不勾选的“同时完成整个任务”，只有周状态完成可选择；切换状态取消选择，浏览器草稿不会恢复该勾选。
- 明确选择后，PATCH 周记录传入 `completeTask: true` 和 `taskVersion`，以实际成果作为整个任务完成说明。周记录、任务、进展和督办处理在同一事务完成。Task 或周版本冲突、权限不足、实际成果缺失及后续写入失败均回滚。
- 普通周完成仍只代表当周完成；不批量修改历史任务，不替代月度成果验收或整份周提报。
