# 天枢实验室界面素材

`lab-icon.png` 与 `lab-wordmark.png` 为用户上传的正式品牌图片，原样保存。页面通过 CSS 控制展示比例和留白，没有重新绘制 Logo。

`monthly-calendar.png` 与 `weekly-clipboard.png` 使用 Codex 内置图像生成工具生成，原始透明通道保留，用于首页月计划与周执行空状态。未使用 CLI；内置工具不暴露可核实的模型选择参数。

生成提示词方向：

- 月计划：独立的蓝白色立体日历插图，白色日历面板、钴蓝色装订环、少量浅蓝细节与柔和半透明光晕；适合现代部门协作产品的空状态。透明背景，中心构图，小尺寸清晰，无文字、数字、Logo 或水印。
- 周执行：与日历相同材质、配色和光照的蓝白色立体任务剪贴板，白色面板、蓝色夹扣和小型完成勾选徽章，轻微立体感和柔和阴影。透明背景，中心构图，小尺寸清晰，无文字、数字、Logo 或水印。

两张生成素材只作装饰，页面使用空 `alt`；状态、日期与操作文字由 HTML 提供。导航与按钮保留 Lucide 矢量图标，保证尺寸统一和键盘可访问性。
